프로젝트

직접 기획하고 테스트까지 설계한 개인 프로젝트입니다. 상태 배지는 진행 단계를 뜻합니다.

  • Checkine

    완료

    B2B SaaS 출결 관리 서비스. 백엔드와 프론트엔드를 직접 구현하고, pytest 49개 테스트 케이스와 CI/CD 파이프라인으로 배포 전 품질을 검증합니다.

    FastAPIVue 3pytestGitLab CI/CDJWT
    검증 포인트 보기
    • pytest 49개 테스트 케이스로 API 동작 검증
    • CI/CD 파이프라인에서 테스트를 자동 실행해 배포 전 회귀 차단
    • JWT 리프레시 토큰 로테이션으로 탈취된 토큰 재사용 방지
    포트폴리오 문서 보기 GitHub 저장소

  • LLM 테스트 케이스 생성기

    진행 중

    OpenAPI 명세와 요구사항을 입력하면 ISTQB 기법에 따라 테스트 케이스를 생성하고, 기존 CSV 기반 pytest 프레임워크에서 바로 실행할 수 있는 형식으로 출력합니다.

    PythonLLM APIOpenAPIpytestCSV
    적용하는 테스트 기법
    • 경계값 분석: 허용 범위 양 끝과 바로 바깥 값
    • 동등 분할: 유효·무효 입력 그룹별 대표값
    • null·빈 값 입력 처리
    • 타입 불일치 입력 처리
